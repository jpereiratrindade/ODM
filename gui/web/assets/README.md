# Identidade visual do Paralaxe

Recursos locais da aplicação independente, distribuídos com o projeto sob sua
licença AGPL v3. O símbolo representa duas perspectivas sobrepostas que convergem
para um ponto. A paleta combina azul-marinho, ciano e âmbar.

| Arquivo | Uso |
| --- | --- |
| `paralaxe.svg` | Símbolo vetorial editável da aplicação |
| `paralaxe-wordmark.svg` | Marca com nome e assinatura nos READMEs |
| `favicon.svg` | Símbolo sobre fundo para a aba do navegador |
| `icon-192.png`, `icon-512.png` | Versões raster usadas pelo manifesto |
| `icons.svg` | Sprite vetorial das ferramentas e dos produtos |

Os SVGs são definidos em código e não dependem de fontes de ícones ou serviços
externos. Ao alterar o símbolo, mantenha favicon e PNGs correspondentes coerentes.
O manifesto está em `../manifest.webmanifest`; cores e dimensões da interface
ficam em `../style.css`. O manifesto não instala um service worker.

A marca Paralaxe identifica a interface. OpenDroneMap mantém seu nome como motor,
suas atribuições e seus recursos originais.
